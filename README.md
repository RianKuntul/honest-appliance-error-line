One honest appliance error message, funny because it tells the truth: a microwave admitting it heated the plate, not the food — and refusing to call that a fault.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) as exactly one line, with no trailing newline.
